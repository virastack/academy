# Tasarım

Tasarım: [Modern Profile Card UI](https://www.figma.com/community/file/1625904675991451970/modern-profile-card-ui-free-figma-template), [@saifullah_nakih](https://www.figma.com/@saifullah_nakih). Lisans: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Kodda değişiklik yapıldı: tasarım React ve Tailwind'e çevrildi.

1. Bağlantıyı açıp **Open in Figma** ile kendi hesabınıza kopyalayın.
2. Kartın çerçevesini seçip bağlantısını alın.
3. İsteğe bağlı: çerçevenin ekran görüntüsünü `card.png` adıyla bu klasöre koyun. Figma MCP çağrı sınırınız dolarsa karşılaştırmayı bununla yaparsınız.
