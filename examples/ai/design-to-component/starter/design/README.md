# The design

The design: [Modern Profile Card UI](https://www.figma.com/community/file/1625904675991451970/modern-profile-card-ui-free-figma-template), [@saifullah_nakih](https://www.figma.com/@saifullah_nakih). The licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The code was changed: the design was converted to React and Tailwind.

1. Open the link and copy it into your own account with **Open in Figma**.
2. Select the card's frame and copy its link.
3. Optional: put a screenshot of the frame into this folder as `card.png`. If you run out of Figma MCP calls, you compare against that instead.
